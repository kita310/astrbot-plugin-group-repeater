# 群聊复读机 (Group Repeater)

AstrBot 群聊复读插件，当同一个群里两个人连续发送一模一样的内容时，机器人跟着复读一次。

## 功能特点

- ✅ 同一条内容只复读一次，避免复读链
- ✅ 支持纯文本和 QQ 内置表情
- ✅ 可选支持图片复读（默认关闭）
- ✅ 可配置冷却时间，防止刷屏
- ✅ 可配置时间窗口，只在指定秒数内的连续消息才触发
- ✅ 可配置文本长度上限
- ✅ 可配置白名单/黑名单群组

## 安装

1. 下载本插件的所有文件
2. 放入 AstrBot 的 `data/plugins/astrbot_plugin_group_repeater/` 目录
3. 重启 AstrBot

## 配置说明

在 AstrBot 后台管理界面的"插件配置"中找到本插件，可配置以下选项：

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable` | 布尔 | `true` | 是否启用群聊复读 |
| `window_seconds` | 整数 | `0` | 判定「连续」的时间窗口（秒）。`0` 表示不限制，两条相同内容隔多久都算连续；设为正数后会严格限制间隔 |
| `cooldown_seconds` | 整数 | `20` | 同一群的复读冷却秒数，防止复读上瘾刷屏；设为 `0` 表示不限制 |
| `max_length` | 整数 | `100` | 参与复读的文本长度上限（字符数），超过这个长度的消息不会触发复读 |
| `repeat_images` | 布尔 | `false` | 是否允许复读图片与表情包。默认关闭：只复读文字和 QQ 内置表情。开启后含图片的消息整条参与复读（注意：QQ 同一张图每次发送的地址可能不同，命中不稳定） |
| `allow_groups` | 字符串 | `""` | 只在这些群生效（群号，逗号分隔）。留空表示所有群都生效 |
| `deny_groups` | 字符串 | `""` | 这些群不生效（群号，逗号分隔）。优先级高于 `allow_groups` |

## 工作原理

1. **触发条件**：同一个群里，**两个不同的人**连续发送相同内容
2. **内容识别**：
   - 默认只识别纯文本和 QQ 内置表情
   - 图片、@、引用、语音、文件、转发消息等默认不参与
   - 可选开启图片复读（`repeat_images`）
3. **复读规则**：
   - 机器人自己的消息不参与判定
   - 同一个人重复发送不触发
   - **同一条内容只复读一次**：复读后会记住这条内容，直到出现别的内容才解除
   - 复读后清空配对记录，需要重新攒够两次才会再触发
4. **时间窗口**（可选）：
   - `window_seconds = 0`（默认）：无论间隔多久都算连续
   - `window_seconds > 0`：两条消息间隔超过此秒数就不算连续

## 示例

### 基础复读

```
用户A: 复读一下
用户B: 复读一下
机器人: 复读一下
```

### 不会触发的情况

```
# 同一个人发两遍 - 不触发
用户A: 不会复读
用户A: 不会复读

# 内容不完全相同 - 不触发
用户A: 复读吗
用户B: 复读吗?

# 机器人已经复读过这条内容 - 不触发
用户A: 已经复读过了
用户B: 已经复读过了
机器人: 已经复读过了
用户C: 已经复读过了  ← 机器人不会再跟
```

### 时间窗口示例

设置 `window_seconds = 30`：

```
用户A: 快速复读  (00:00)
用户B: 快速复读  (00:05)  ← 间隔 5 秒，触发复读
机器人: 快速复读

用户A: 慢速复读  (00:00)
用户B: 慢速复读  (00:35)  ← 间隔 35 秒 > 30 秒，不触发
```
